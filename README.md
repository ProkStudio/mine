# Harvester Mod

Мод для **Fabric / Minecraft 1.21.11**: управляемый комбайн собирает зрелые ванильные культуры, складывает добычу в свой инвентарь и тратит топливо во время движения.

## Возможности

- Комбайн имеет 100 единиц здоровья, не сдвигается мобами и выбрасывает груз при уничтожении.
- Сбор поддерживает пшеницу, морковь, картофель, свёклу, какао, сладкие ягоды, адский нарост, сахарный тростник, тыквы и арбузы.
- Обычные культуры и адский нарост после сбора сразу остаются посаженными на первой стадии роста; для тыкв и арбузов сохранены стебли.
- `Shift + ПКМ` открывает стандартный инвентарь на 27 слотов. Его содержимое сохраняется после перезапуска мира.
- `ПКМ` садит игрока за руль. Во время движения используйте WASD; уголь добавляет 80 топлива, блок угля — 800. Железный слиток восстанавливает 10 здоровья.

## Крафт

Модуль призыва комбайна создаётся из 7 железных блоков, ножниц, воронки и вырезанной тыквы:

```
Ж Н Ж
В Т В
Ж Ж Ж

Ж — железный блок, Н — ножницы, В — воронка, Т — вырезанная тыква
```

Используйте модуль на земле, чтобы призвать комбайн.

## Настройка

При первом запуске создаётся файл `config/harvester.json`. В нём можно поменять:

- `maxFuel` — запас топлива;
- `fuelPerTick` — расход при движении;
- `drivingSpeed` — скорость;
- `harvestRadius` — радиус сбора от 0 до 4;
- `harvestIntervalTicks` — частоту проверки посевов.

Для игры нужны Fabric Loader 0.19.5+ и Fabric API для Minecraft 1.21.11. Для разработки нужен JDK 21.

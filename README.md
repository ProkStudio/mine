# Harvester Mod

Мод для **Fabric / Minecraft 1.21.11**: управляемый комбайн с бункером на 27 слотов.

## Управление

- `ПКМ` пустой рукой — сесть. WASD — движение; задний ход и движение вбок медленнее переднего.
- `Shift` — выйти. `Shift + ПКМ` по комбайну — открыть бункер.
- `ПКМ` с углём или древесным углём — добавить 80 топлива; с блоком угля — 800.
- `ПКМ` с железным слитком — восстановить 10 прочности.
- `ПКМ` с ножницами — включить/выключить жатку. Выключенная жатка приподнята: это транспортный режим. Ножницы не расходуются.
- Строка состояния водителя показывает топливо, число занятых слотов и состояние жатки.

**Новый комбайн появляется без топлива.** Это исключает бесплатную заправку через разрушение и повторный призыв. Уже сохранённое топливо сохраняется.

## Уборка

- Уборка работает при движении комбайна с водителем и включённой жаткой. На стоянке топливо не тратится и урожай не собирается.
- Обрабатываются две полосы блоков перед жаткой; `harvestRadius` задаёт полуширину захвата, а не круг вокруг машины.
- Поддерживаются зрелые пшеница, морковь, картофель, свёкла, адский нарост, какао, сладкие ягоды, сахарный тростник, тыквы и арбузы. Стебли тыквы/арбуза не трогаются.
- Для пересадки расходуется один соответствующий предмет из полученного урожая. Если материала нет, растение остаётся нетронутым. Кусты ягод остаются на стадии 1, какао сохраняет ориентацию.
- Тростник снимается сверху вниз, основание остаётся. Высокие стебли за пределами захвата не ломаются посередине.
- Перед изменением растения проверяется, влезает ли **весь** урожай. Если места недостаточно, этот блок и груз не меняются: предметы не высыпаются на землю.
- Неизвестные культуры других модов пропускаются до добавления корректного правила пересадки.

## Модель и сохранение

Исправлены оси колёс, собственный центр вращения мотовила и высота колёс над землёй. Добавлены бункер зерна, лестница, делители и зубья жатки, сложенный выгрузной шнек. Шнек пока только декоративный: разгрузка через инвентарь.

Используется существующая текстура 128×128. Вращение мотовила останавливается без сброса угла; меньшие задние колёса вращаются быстрее передних. Состояние жатки, топливо и груз сохраняются вместе с базовыми данными сущности, включая здоровье. Комбайн не должен естественно исчезать; при разрушении выпадают груз и модуль.

## Крафт

```
Ж Н Ж
В Т В
Ж Ж Ж

Ж — железный блок (5), Н — ножницы (1), В — воронка (2), Т — вырезанная тыква (1)
```

Схему сверяйте с рецептом установленной версии мода.

## Настройка

Файл `config/harvester.json` создаётся при первом запуске:

- `maxFuel` — запас топлива (по умолчанию 1600);
- `fuelPerTick` — расход за тик движения (по умолчанию 1; 0 отключает расход, но заправка для запуска всё равно нужна);
- `drivingSpeed` — скорость (0.05–1.0);
- `harvestRadius` — полуширина уборки (0–4, по умолчанию 1);
- `harvestIntervalTicks` — интервал проверок (1–100, по умолчанию 5).

Бункер фиксирован: 27 слотов. Нечисловая или бесконечная скорость заменяется безопасным значением 0.25. При игре по сети используйте одинаковые настройки клиента и сервера: отдельная синхронизация конфига пока не реализована.

## Проверки

Для игры нужны Fabric Loader 0.19.5+ и Fabric API для Minecraft 1.21.11.

```bash
# JDK 21+; автономные тесты правил движения, конфигурации и геометрии
bash tests/run.sh
# Полная сборка с зависимостями Minecraft/Fabric
./gradlew build
```

Автономные тесты запускаются вручную командой выше. Они **не заменяют** игровые проверки. План ручной проверки и ограничения: [docs/COMBINE-QA.md](docs/COMBINE-QA.md).

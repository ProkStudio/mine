# Проверка улучшений комбайна

## Проверено в рабочей среде

- Компиляция автономных правил с `--release 21` и запуск регрессионных тестов.
- Синтаксический разбор изменённых Java-файлов.
- Парность ключей русской/английской локализации.

## Требует Minecraft и полной сборки

В среде подготовки изменений нет доступа к серверам зависимостей Minecraft/Fabric. Полная сборка и запуск игры здесь не выполнены. Не считайте синтаксическую проверку подтверждением совместимости с API 1.21.11. Перед слиянием дождитесь зелёного CI и пройдите этот список на копии мира.

- [ ] Новый комбайн пустой; coal/charcoal добавляют 80, coal block — 800, предел не превышается.
- [ ] Водитель на стоянке не тратит топливо; без топлива ехать нельзя; задний ход медленнее.
- [ ] Проверить управление двумя клиентами на выделенном сервере, остановку после спешивания и синхронизацию движения.
- [ ] Жатка убирает только спереди при направлениях 0°, 45°, 90°, 180°, 270°.
- [ ] Все поддерживаемые зрелые культуры собираются, незрелые остаются; пересадка тратит один предмет из добычи.
- [ ] Какао сохраняет ориентацию; ягоды переходят к стадии 1; стебли тыкв и арбузов остаются.
- [ ] Полный бункер и частично заполненные стаки: блок остаётся целым, если весь урожай не помещается; дубликатов и выпавших предметов нет.
- [ ] Тростник высотой 2/3: основание остаётся, верх собирается в бункер; переполненный бункер не роняет верхушку.
- [ ] Сохранить повреждённый комбайн с грузом и отключённой жаткой, перезагрузить мир: здоровье/груз/топливо/режим сохранены. Проверить старое сохранение без HeaderEnabled.
- [ ] Разрушение выдаёт груз один раз; повторный призыв не даёт бесплатного топлива.
- [ ] Открытый инвентарь закрывается при удалении сущности или отдалении более 8 блоков.
- [ ] От первого/третьего лица проверить посадку, камеру, землю под колёсами, вращение колёс/мотовила и поднятую жатку. Проверить исходную текстуру на новых деталях.
- [ ] Проверить лестницу и выгрузную трубу в разных ракурсах. Труба декоративная, автоматической выгрузки нет.

Ограничения: поворот следует взгляду игрока; автомобильная физика с инерцией не вводилась. Синхронизация настроек сервера и интеграция с модами защиты территорий требуют отдельной реализации. На высокой скорости/при большом интервале уборки возможны пропуски полос; рекомендуются значения по умолчанию.

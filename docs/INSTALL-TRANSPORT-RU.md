# Harvester Transport Pack 1.3.0-rc.1 — установка

Это **prerelease / кандидат в релиз**, не подтверждённая стабильная игровая сборка. Сначала используйте отдельный профиль и копию мира.

## Требования

- Minecraft **1.21.11**, Fabric (не Forge/NeoForge).
- Java 21 для игры; JDK 21 для самостоятельной сборки.
- Сборка подготовлена с Fabric Loader **0.19.5** и Fabric API **0.141.6+1.21.11**. Используйте эти версии для воспроизводимой проверки.
- Для сетевой игры мод и Fabric API нужны на сервере и у всех клиентов. Согласуйте конфигурации.
- Другие версии Minecraft, Iris, shader pack и сторонние моды не прошли приёмку совместимости.

## Установка

1. Закройте игру/сервер. Сделайте резервную копию мира и `config/harvester.json`.
2. Установите профиль Fabric для Minecraft 1.21.11 и подходящий Fabric API.
3. Скачайте `harvester-mod-1.3.0-rc.1.jar` либо ZIP выпуска. В ZIP готовый JAR лежит в папке `mods/`. Автоматический архив GitHub «Source code» — исходники, не готовый мод.
4. Уберите прежний JAR Harvester из `mods/` и положите новый. Не оставляйте две версии Harvester одновременно; остальные моды удалять не требуется.
5. Запустите отдельный тестовый профиль и копию мира. Модели, звуки и локализации уже внутри JAR; отдельный ресурспак и FFmpeg для игры не нужны.

## Проверка загрузки

Найдите creative-вкладку **Harvester — техника и заправка**. Рецептов нет. В игровом чате с разрешёнными командами можно использовать:

```mcfunction
/give @s harvester:pickup
/give @s harvester:motorcycle
/give @s harvester:combine_spawn_egg
/give @s harvester:fuel_can_large
```

Поставьте транспорт ПКМ предметом по свободному месту в Overworld. Катер ставится на воду. Новая машина без топлива: заправьте канистрой через ПКМ.

## Быстрое управление

- ПКМ по технике — сесть; Shift — выйти.
- Наземная техника и катер: W/S — движение/реверс, A/D — поворот.
- Авиация: W — тяга по плавно меняющемуся направлению взгляда; S — торможение. Самолёту нужен разбег; Space помогает взлёту.
- Вертолёт/дрон: Space — вверх, клавиша спринта (обычно Ctrl) — вниз. **Shift не используется для снижения**.
- Сундук в руке + ПКМ — груз; Shift + ПКМ — забрать машину предметом (нужен свободный слот).
- Ножницы + ПКМ по комбайну — поднять/опустить жатку; работа при движении остаётся автоматической.
- Полное управление, ограничения физики и настройки — в README репозитория.

## Звук

Клиентская настройка: `config/harvester-client.properties`, `engineVolume=0.65` в диапазоне 0–1; 0 отключает двигатель. После изменения перезапустите клиент. Проверьте также игровую категорию «Дружелюбные существа». Шесть звуковых профилей синтезированы специально для мода, а не записаны с реальной техники.

## Миграция и откат

Идентификаторы вариантов, ID сущности `harvester:combine`, число мест и схема сохранения в этой итерации не менялись. Но размеры техники стали **на 12.5% больше**: проверьте плотную парковку, крыши и узкие проезды в копии мира. Старый конфиг не нужно удалять; при миграции мод может создать рядом `harvester.example.json`.

Совместимость сохранённых миров ещё требует игровой приёмки. Для отката закройте игру и восстановите **полную резервную копию мира и прежний JAR**. Не рассчитывайте на безопасный откат только заменой JAR после сохранения мира новой версией.

## Контрольные суммы

Скачайте `SHA256SUMS` рядом с файлами выпуска. В Linux: `sha256sum -c SHA256SUMS`; в macOS: `shasum -a 256 -c SHA256SUMS`. Для проверки всего списка нужны все перечисленные файлы рядом. В Windows: `Get-FileHash .\harvester-mod-1.3.0-rc.1.jar -Algorithm SHA256` и сравнение со строкой в `SHA256SUMS`. Внутри ZIP есть отдельный `CONTENTS.sha256`.

При ошибке приложите версию, вариант техники, шаги воспроизведения, `latest.log` или crash report и список клиентских модов. Журнал может содержать адреса серверов и личные данные — просмотрите его перед публикацией.

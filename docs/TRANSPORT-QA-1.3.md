# Transport 1.3 — журнал приёмки

## Что действительно проверено

- Независимые Java-классы скомпилированы с target Java 21. Финальный локальный polish-smoke: **583108 внутренних assertions**, 16 вариантов. Это НЕ число JUnit-методов.
- Первый интегрированный коммит `57b5b727dd5197e0d40608a7c0f2d6047642f4b3` прошёл полный client/Fabric build, 59 обязательных JUnit-методов, оба smoke и сверку геометрии: https://github.com/ProkStudio/mine/actions/runs/34140390074. Позднейшие исправления обязаны пройти отдельную свежую проверку; результат выпуска записывается в BUILD-INFO.json.
- Шесть OGG декодированы: mono 32000 Hz, 128000 сэмплов; RMS около −18.5 dBFS, пик ниже 0.48, измерены DC и граница цикла. Повторная генерация тем же локальным encoder совпала byte-for-byte. Прослушивание не выполнено.
- Просмотрены отдельные изометрические офлайн-изображения всех 16 вариантов и комбайна с поднятой жаткой. Данные изображения используют реальную геометрию, но **без стекла, UV-текстур, игрока и Minecraft**.
- Осмотр выявил совпадающие поверхности на подножках мотоцикла, тягах и боковинах гусениц бульдозера. Геометрия разделена по глубине, добавлены численные регрессионные проверки; изменённые виды повторно отрендерены и просмотрены.
- SHA-256 экспортов связывает локально осмотренную геометрию с геометрией, собранной в CI. Изменение fingerprint без осмотра не является исправлением теста.

## Обязательная игровая приёмка до stable — НЕ ПРОЙДЕНА

- [ ] Все 16 вариантов: постановка, движение, повороты, реверс/торможение, выход, подбор, сохранение/перезагрузка.
- [ ] Обычный/slim-скин, разные комплекты брони; два пассажира мотоцикла; контакт конечностей, использование предметов и атака.
- [ ] Первый/третий вид, свободная камера, границы frustum; длинные крылья/жатки на краю кадра.
- [ ] Работающие/остановленные механизмы, дождь/парковка дворников, подвеска, гидравлика во всём диапазоне.
- [ ] Вода/берег, затопление авиации, препятствия, узкие проезды и парковка после увеличения размеров.
- [ ] Звук в наушниках/колонках: холостой ход, нагрузка, остановка, 16 голосов, смена мира/типа, настройки громкости.
- [ ] Resource reload, атласы/стекло/лампы в Minecraft; при необходимости отдельные shader pack.
- [ ] Несколько клиентов и машин, лаг/потеря пакетов, выгрузка чанков, замеры времени кадра и памяти.

Не отмечать эти пункты по результату компиляции, скриншотам без игры или числам из аудиоанализа. Обнаруженные ошибки фиксировать с версией/коммитом, шагами и логом.

## Сейчас: выпуск RC

Workflow `Transport RC release` выполняет свежий clean build с Java 21, строгий verifier 59 методов, правила/visual-smoke/polish-smoke, fingerprints всех моделей и проверку remapped JAR. Затем упаковывает ZIP/установку/лицензию/QA/BUILD-INFO/SHA256SUMS. Публикация только как prerelease `v1.3.0-rc.1`: существующие тег/релиз не заменяются. Загруженные файлы повторно скачиваются и проверяются до публикации.

**Пока не писать, что выпуск опубликован:** подтвердить это по `docs/TRANSPORT-RELEASE-CHECKPOINT.json` и GitHub Releases. Результаты и диагностические выдержки сохраняются workflow автоматически в `docs/TRANSPORT-CI-LAST.log`; отдельный исторический сбой PR диагностируется в `docs/TRANSPORT-CI-PR-DIAGNOSTIC.log`. При ошибке сначала читать эти файлы, исправить причину и не обходить защиту тегов/тестов.

После успешной публикации: обновить этот файл действительной ссылкой и точным release SHA; обновить описание PR #5. Main и ветку оружия не трогать. PR остаётся draft до игровой приёмки.

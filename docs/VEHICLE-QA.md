## Полёт — все шесть авиационных вариантов

- [ ] Сервер получает поворот взгляда водителя во время езды; машина плавно следует взгляду, второй наблюдатель видит тот же курс. Проверить с сетевой задержкой.
- [ ] W даёт тягу, S тормозит без реверса; без W камера не создаёт горизонтальную тягу. Наземное управление не сломано.
- [ ] Самолёт не взлетает без разбега, после >4.4 блока/с W + взгляд вверх/Space дают подъём. Без W — снижение, не висение.
- [ ] Вертолёт/дрон: вертикальный взлёт, подъём/снижение, устойчивое висение, потолок мира. Shift именно высаживает.
- [ ] На земле без ввода топливо не расходуется. В воздухе powered flight/hover расходуют max(1, movementFuel) за тик, включая movementFuel=0.
- [ ] Пустой бак, поломка, выход водителя: тяга и висение прекращаются; нет незаказанного урона/катапультирования.
- [ ] Timeout: нет старой тяги, вертикальная авиация с водителем и топливом удерживает высоту; без водителя снижается.
- [ ] Погружение двигателя выключает тягу/подъём/висение даже при W + Space и взгляде вверх; RUNNING/частицы прекращаются. Краткое касание крылом не равно затоплению двигателя.
- [ ] Воздух → вода → берег/воздух; загрузка старой сохранённой авиации под водой; pickup/reload с полным грузом и топливом.
- [ ] Границы мира/незагруженные чанки проверяются по footprint; нет проталкивания в блоки.

## Катера — оба варианта

- [ ] Глубокая вода: устойчивое положение на ватерлинии, отсутствие нарастающей раскачки.
- [ ] Течение, мелководье, край воды, берег, столкновение; краткая потеря контакта не обрывает скорость в ноль, но не позволяет разгоняться на суше.
- [ ] Плавные A/D, боковое сопротивление, ограниченный задний ход и ожидаемый поворот при реверсе.
- [ ] Без водителя/топлива катер продолжает пассивно плавать, не разгоняется двигателем; загрузка с грузом не теряет состояние.
- [ ] Движение у водителя и наблюдателя, включая задержку сети; жалоба на рывки проверена, а не объявлена решённой только по формулам.

## Эффекты и оставшийся визуальный этап

- [ ] Нет поршневого звука раз в секунду. На этом этапе отсутствие звука двигателя ожидаемо; собственные OGG ещё не готовы.
- [ ] Дым у выхлопа виден рядом и другому игроку; у дрона/вертолёта нет универсального дизельного дыма. Дым не появляется в твёрдом мировом блоке.
- [ ] Брызги у кормы только при движении в воде; настройки частиц соблюдаются, Minimal не обещает видимость.
- [ ] Будущая посадка: координаты кресел, оба места мотоцикла, камера не в крыше/кузове, свободный обзор без вращения таза. Пока не реализовано.
- [ ] Будущий риг: working отдельно от engineActive, плавные роторы/жатка/руль/подвеска, согласованный наклон пассажира и корпуса. Пока не реализовано.
- [ ] Будущий звук: лицензированные/собственные mono OGG, looping lifecycle, отсутствие копий, остановка при выгрузке/смене мира; проверка конечного JAR и прослушивание. Пока не реализовано.

## Ограничения

- Простая игровая физика, не реалистичная авиация. Чувствительность водных проб/камера/задержка требуют проверки на сервере.
- Старое правило бесплатного висения отменено новым планом; цена висения указана выше.
- Поднятая ножницами жатка — визуальное положение, не выключатель уборки.
- Неизвестные модовые культуры не убираются автоматически.
- Проверить вложенные контейнеры/шалькеры на размер NBT и отсутствие нежелательного вложения техники.
- Весь старый мир не протестирован; первая загрузка только с резервной копией.

# Military Arsenal — 0.1.0

Самостоятельный оружейный мод в репозитории `ProkStudio/mine`. **Minecraft 1.21.11 · Fabric Loader 0.19.5+ · Fabric API 0.141.6+1.21.11 · JDK 21.** Namespace: `arsenal`.

> Первая реализация, не сертифицированный игровой релиз. Автономные тесты ядра/ресурсов и аудиогенератор запускались. Первый полный коммит успешно прошёл Fabric-сборку и JUnit в отдельном workflow **Military Arsenal**; проверяйте статус последнего коммита. Запуск в игре, двухклиентская проверка и полная визуальная приёмка пока не подтверждены. Не заменяйте основной игровой мир без резервной копии.

## Состав

| Категория | Оружие | Отличие |
| --- | --- | --- |
| Пистолеты | Kestrel P9, Bastion .45 | Лёгкий быстрый и тяжёлый варианты |
| Револьвер | Marshal R6 | Шесть патронов, поштучная перезарядка |
| ПП | Viper SM9, Warden SD | Автоматический огонь; Warden тише |
| Автоматы | Lynx C5, Boreal R7, Trident B3 | Разные магазины, точность и режимы; Trident — отсечка по три |
| Дробовики | Breaker P12, Tempest A12 | Помповый/автоматический; дробь либо пуля |
| Винтовки | Sentinel D7, Longwatch S1 | Оптика, увеличенная дальность, разный темп |
| Пулемёт | Bulwark L5 | Магазин 80, долгая перезарядка, сошки на модели |
| Гранатомёт | Arc G40 | Шесть гранат, навесная траектория, HE или дым |
| РПГ | Atlas RPG, Titan AT | Atlas принимает четыре типа ракет; Titan — AP и учебные |

**14 видов боеприпасов:** light, heavy, magnum, intermediate, rifle, precision, buckshot, slug, grenade HE/smoke, rocket HE/AP/smoke/practice. Полные идентификаторы находятся в `src/main/java/dev/mine/arsenal/core/Ammo.java`.

- HE: площадной урон с ослаблением по расстоянию и проверкой препятствий.
- AP: высокий прямой урон с обходом ванильной брони и меньший радиус. Это игровая механика, не моделирование настоящей бронетехники. Совместимость с уроном конкретных транспортных модов требует проверки.
- Smoke: ограниченное по времени облако; это визуальная завеса, она не меняет зрение AI мобов.
- Practice: инертный снаряд без урона и взрыва.

## Управление

- **ЛКМ / стандартная «Атака»** — огонь. Автоматическое оружие стреляет при удержании.
- **ПКМ / стандартное «Использовать»** — удерживать прицеливание.
- **R** — перезарядка.
- **V** — следующий доступный режим огня.
- **B** — следующий тип боеприпасов, только при пустом оружии.
- **H** — осмотр.
- **Спринт, смена оружия, смерть, выход и устаревший ввод** отменяют перезарядку/действие. Загруженные патроны сохраняются.
- **ЛКМ во время поштучной перезарядки** прерывает её, если уже есть патрон.

Клавиши R/V/B/H переназначаются в категории «Военный арсенал». HUD показывает магазин, режим, боеприпас, запас и ход перезарядки; подсказка R использует текущую привязку.

Огонь работает только из основной руки; ведущая левая рука поддержана визуально. Dual-wield не реализован. Для открытия сундука, постановки блока или обычной добычи уберите оружие из основной руки: оно перехватывает кнопки атаки/использования.

## Получение

30 предметов доступны в creative-вкладке **Военный арсенал**. Оружие появляется пустым: нажмите R. В creative перезарядка не требует расходников. В survival нужны подходящие патроны в обычном инвентаре.

Есть 30 уникальных рецептов; они открываются в книге при получении железа/меди. Рецепты абстрактные игровые, без изготовления реального оружия. Цвет красителя различает варианты. Полученные модели не требуют стороннего ресурспака.

```mcfunction
/give @s arsenal:kestrel_p9
/give @s arsenal:light_round 64
/give @s arsenal:lynx_carbine
/give @s arsenal:intermediate_round 64
/give @s arsenal:atlas_rpg
/give @s arsenal:rocket_ap 16
/give @s arsenal:rocket_smoke 16
/give @s arsenal:rocket_practice 16
```

Чтобы зарядить AP в Atlas: опустошите его, B до AP, затем R.

## Графика и звук

`WeaponGeometry` — единый редактируемый источник оригинальных voxel-моделей. `ArsenalAssets` генерирует 350 моделей/кадров: 16 × 21 состояние и 14 моделей боеприпасов. 27 оригинальных текстур 32×32, независимые трансформации GUI, ground, fixed, обеих рук от первого/третьего лица. Выброшенный предмет остаётся объёмным; GUI и рамки используют спокойную модель, не случайный кадр перезарядки.

Затвор, магазин, цевьё, барабан и ракета имеют собственные группы. Клиент добавляет плавные движения отдачи, прицеливания и осмотра; сервер синхронизирует дискретные кадры механизмов и позы. Это собственная система, без GeckoLib. Полноценной кинематики пальцев и motion capture нет. Отдача визуальная: мод не насильно меняет yaw/pitch игрока.

Пули используют hitscan; гранаты и ракеты — настоящие синхронизируемые projectile entities, свои 3D-модели, гравитацию, столкновения и след. В полёте модели боеприпасов ориентируются по направлению снаряда. Снаряды не сохраняются между перезапусками и не загружают новые чанки.

12 оригинальных синтезированных звуков проходят кодирование в mono Vorbis и обратное декодирование с проверкой тишины/клиппинга. Они позиционные, относятся к категории «Игроки», имеют RU/EN субтитры. Сторонние записи и чужие ресурс-паки не используются.

## Серверная логика и настройки

Клиент передаёт только биты кнопок — не цели, урон, патроны, координаты или скорость стрельбы. Сервер сам определяет оружие, магазин, задержки, прицел и попадание. Пакеты объединяются по игровым тикам. Отдельный тайм-аут прекращает старый ввод. Cooldown сохраняется при смене слотов.

Магазин, тип патронов и режим сохраняются в компонентах ItemStack; анимационные таймеры не копируются в сохранение. Перезарядка списывает реально найденные патроны только при завершении этапа. Поштучная загрузка используется у револьвера, помпового дробовика и гранатомёта. Переключение типа заряженных патронов запрещено.

`config/military-arsenal.json` создаётся при первом запуске. Перезапустите сервер после изменения:

- `enabled`: весь мод боевых действий, по умолчанию true.
- `pvpDamage`: урон другим игрокам, **false** по умолчанию. При включении дополнительно действует обычная проверка PvP/команд Minecraft. Самоповреждение взрывом возможно.
- `explosions`: урон боевых гранат/ракет, true. **Блоки и огонь не меняются в любом случае.**
- `damageMultiplier`: 0..4, по умолчанию 1.
- `smokeCloudLimit`: 0..24 облака на измерение, по умолчанию 12.
- `projectileLimitPerPlayer`: 1..16 запусков за защитное окно, по умолчанию 8.
- `inputTimeoutTicks`: 3..12, по умолчанию 8.

Повреждённый конфиг не перезаписывается. Нет автоматического самонаведения, пробития стен, гранат с рикошетом, систем бронелистов или собственных танков. Harvester не является зависимостью; его исходники не менялись.

## Сборка и установка

Из корня репозитория:

```bash
bash military-arsenal/tests/run.sh
bash ./gradlew -p military-arsenal clean build
(cd military-arsenal && python3 tests/verify_junit.py)
```

Либо внутри папки: `sh gradlew clean build`; Windows: `gradlew.bat clean build`. Используется существующий wrapper репозитория (Gradle 9.2.0). Если скопировать папку отдельно, установите Gradle 9.2.0. Для автономного тестового скрипта нужен Python 3; JUnit/resource checks внутри Gradle не зависят от Python.

Сборка автоматически создаёт PNG/JSON/OGG и помещает их в jar. Поэтому отсутствие сотен сгенерированных файлов в `src/main/resources` намеренное, а не недоделка. Аудиокодер JAVE 4.2.0/FFmpeg — только build-time, не входит в мод. Свой FFmpeg можно указать:

```bash
bash ./gradlew -p military-arsenal clean build -ParsenalFfmpeg=/absolute/path/to/ffmpeg
```

После успешной сборки используйте `military-arsenal/build/libs/military-arsenal-0.1.0.jar`, **не** `-sources.jar`. Установите одинаковый мод и совместимый Fabric API в папку `mods` клиента и сервера. Jar появляется в GitHub Actions artifacts только если соответствующий этап сборки выполнен.

План ручной приёмки и точные ограничения проверки — [docs/QA.md](docs/QA.md). Не смешивайте успех автономных тестов с подтверждением работоспособности игры.

# Military Arsenal — 0.1.1

Отдельный оружейный мод в `ProkStudio/mine`. **Minecraft 1.21.11 · Fabric Loader 0.19.2+ · Fabric API 0.141.6+1.21.11 · Java 21.** Namespace: `arsenal`. Harvester не является зависимостью; транспортный код не изменён.

> Полную сборку проверяйте по CI последнего коммита. Успешные автономные тесты и сборка не означают, что выполнена игровая приёмка. Используйте отдельный тестовый мир и резервную копию.

## Исправления 0.1.1

- PNG перенесены из `textures/material` в `textures/item/material`: теперь их находит стандартный атлас предметов. Проверяется не только наличие файла, но и доступность пути для атласа.
- Нос ракеты/гранаты поворачивается по вектору скорости, а не по несовместимой трактовке yaw сущности. Проверены математически все стороны света, диагонали и вертикальный полёт.
- Убрана длинная строка из tooltip; HUD уже. Справка показывает реальные переназначенные клавиши.
- B переключает боеприпасы без необходимости отстреливать магазин: старый заряд возвращается в инвентарь, затем R заряжает выбранный тип.
- Добавлены две отдельные ручные гранаты — HE и дымовая, со своими моделями, рецептами и серверным ограничением бросков.
- 19 mono Vorbis-файлов, 44.1 kHz: многослойный удар, низкий тон, шум и затухание, по два варианта семи выстрелов. Щелчки остаются только у механизмов и пустого оружия. Это оригинальный синтез, не записи настоящего оружия.
- Минимум Loader задаётся одной настройкой `loader_version=0.19.2`; из неё заполняется `fabric.mod.json`. Сборка проверяет также манифест внутри готового jar.

## Управление

| Клавиша по умолчанию | Действие |
| --- | --- |
| ЛКМ | Огонь; удержание для AUTO |
| ПКМ с оружием | Удерживать прицеливание |
| R | Перезарядка выбранным типом |
| B | Следующий совместимый тип боеприпаса |
| V | Режим огня |
| H | Осмотр — только анимация |
| K | Открыть/закрыть справку |
| ПКМ с ручной гранатой | Бросить, не чаще раза в секунду |

Привязки меняются в «Настройки → Управление → Военный арсенал». K в предыдущей реализации этого модуля не назначалась; в 0.1.1 это справка. Если другой мод использует K, переназначьте одну из команд.

**Как зарядить AP в Atlas:** возьмите Atlas, нажимайте B до противотанковой ракеты, затем R. Выбранный тип виден в HUD. В survival нужные ракеты должны быть в инвентаре; creative не требует расходников.

B отменяет текущую перезарядку и возвращает именно прежний тип патронов. При полном инвентаре остаток выпадает рядом. В creative прежний заряд удаляется без создания бесплатных предметов. Для оружия с единственным типом B ничего не выгружает и объясняет причину.

Спринт, смена оружия, смерть, выход и тайм-аут ввода отменяют действие. Уже загруженные патроны сохраняются. ЛКМ прерывает поштучную перезарядку, если уже есть патрон.

Огонь работает из основной руки. Для взаимодействия с блоками или броска гранаты уберите оружие из основной руки: оно перехватывает кнопки мыши. Ведущая левая рука поддержана визуально; dual-wield не реализован.

## Оружие и получение

16 единиц: Kestrel P9, Bastion .45, Marshal R6, Viper SM9, Warden SD, Lynx C5, Boreal R7, Trident B3, Breaker P12, Tempest A12, Sentinel D7, Longwatch S1, Bulwark L5, Arc G40, Atlas RPG, Titan AT.

14 видов оружейных боеприпасов + 2 ручные гранаты. Всего **32 предмета и 32 рецепта** во вкладке «Военный арсенал». Оружие появляется пустым: R для зарядки. Рецепты открываются при получении железа/меди; они абстрактные игровые, не инструкции по изготовлению настоящего оружия.

```mcfunction
/give @s arsenal:atlas_rpg
/give @s arsenal:rocket_ap 16
/give @s arsenal:rocket_smoke 16
/give @s arsenal:rocket_practice 16
/give @s arsenal:frag_grenade 16
/give @s arsenal:smoke_grenade 16
```

Ручные `frag_grenade` / `smoke_grenade` бросаются ПКМ. Это **контактные** гранаты: срабатывают при столкновении либо через 2 секунды полёта; рикошетов и удержания чеки нет. `grenade_he` / `grenade_smoke` — отдельные боеприпасы для Arc G40, не ручные гранаты.

HE наносит площадной урон с ослаблением и проверкой препятствий; AP — высокий прямой урон с обходом ванильной брони, не симуляция бронелистов. Дым — визуальная завеса, не AI-stealth. Учебная ракета инертная. Atlas принимает HE/AP/дым/учебные; Titan — AP/учебные; дробовики — дробь/пулю.

## Ресурсы и сервер

352 генерируемые модели/кадра, 27 оригинальных текстур 32×32; первый/третий вид, обе ведущие руки, GUI, земля и рамки. Подвижные затворы/магазины, ADS, отдача, осмотр и HUD без GeckoLib. Пули hitscan; гранаты/ракеты — сущности с гравитацией и столкновениями. Модели оружия редактируются в `WeaponGeometry`, ручных гранат — в `GrenadeGeometry`.

Клиент передаёт только кнопки. Сервер определяет цели, урон, боезапас и темп; ограничивает броски и общий бюджет снарядов. Боезапас/режим сохраняются в ItemStack. Снаряды не сохраняются после перезапуска и не загружают новые чанки. Звуки позиционные, категория «Игроки», субтитры RU/EN.

`config/military-arsenal.json` создаётся при запуске. После изменения перезапустите сервер:

- `enabled`: включить действия мода, true.
- `pvpDamage`: урон другим игрокам, **false**. Дополнительно учитываются PvP/команды Minecraft.
- `explosions`: урон взрывов, true. **Блоки и огонь не меняются.** Самоповреждение возможно.
- `damageMultiplier`: 0..4, по умолчанию 1.
- `smokeCloudLimit`: 0..24 на измерение, по умолчанию 12.
- `projectileLimitPerPlayer`: 1..16 за окно 100 тиков, по умолчанию 8; общий для ракет, гранатомёта и бросков.
- `inputTimeoutTicks`: 3..12, по умолчанию 8.

Повреждённый конфигиг не перезаписывается. Самонаведения, пробития стен, танков и моделирования реальной брони нет.

## Сборка и установка

Из корня репозитория:

```bash
bash military-arsenal/tests/run.sh
bash ./gradlew -p military-arsenal clean build
(cd military-arsenal && python3 tests/verify_junit.py)
```

Нужны JDK 21 и wrapper Gradle 9.2.0 из корня. Внутри модуля можно использовать `sh gradlew clean build`, Windows — `gradlew.bat clean build`. Python 3 нужен автономным тестам, но не JUnit. PNG/JSON/OGG генерируются при сборке. JAVE/FFmpeg — только build-time, в мод не входят; свой кодер: `-ParsenalFfmpeg=/absolute/path/to/ffmpeg`.

После успешной сборки установочный файл — **`military-arsenal-0.1.1.jar`**, не `-sources.jar`, в `military-arsenal/build/libs/`. В GitHub: workflow **Military Arsenal → успешный запуск → Artifacts → military-arsenal-<commit>**.

Удалите старый jar и установите новый вместе с совместимым Fabric API на клиент/сервер. **Не держите две версии мода одновременно.** Полностью перезапустите игру. Указанный профиль TLauncher с Fabric Loader **0.19.2** теперь удовлетворяет требованию мода; менять профиль ради прежнего порога 0.19.5 не нужно.

Ручные проверки: [docs/QA.md](docs/QA.md). Изменения и отдельный план регрессии 0.1.1: [docs/FIXES-0.1.1.md](docs/FIXES-0.1.1.md).

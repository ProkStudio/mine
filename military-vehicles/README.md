# Military Vehicles — 0.3.0-alpha.1

Самостоятельный наземный пак для **Minecraft 1.21.11 · Fabric Loader 0.19.5+ · Fabric API · Java 21**. Работа ведётся в `feature/military-vehicles`, [PR #6](https://github.com/ProkStudio/mine/pull/6). Harvester и Military Arsenal не нужны и не изменены.

**Восемь машин с действующими ролями**, а не перекраски: перевозка, разведка, экипаж, гусеничный танк, снабжение, ремонт, эвакуация и развёртываемая самоходка. Параметры и техника вымышленные. Это собираемая **alpha**, не завершённая игровая приёмка и не stable.

## Быстрый старт

1. Поставить машину ПКМ предметом по свободной ровной площадке. Канистра + ПКМ заправляет, ремкомплект + ПКМ ремонтирует.
2. Сундук в руке + ПКМ открывает груз; сундук не расходуется. Снаряды и запасные ремкомплекты кладутся **в груз машины**.
3. ПКМ — сесть; **G** — двигатель; **W/S** — тяга/реверс; **A/D** — поворот; **Space** — тормоз; **Shift** — выйти.
4. **Z** — выстрел либо обслуживание; **V** — опоры самоходки; **C** — сменить пост одиночного экипажа; **K** — справка. Эти пять специальных клавиш переназначаются. Z не конфликтует с ванильной F смены рук.
5. Для упаковки: остановиться, убрать опоры, высадить всех, освободить слот и нажать Shift + ПКМ. Груз, имя, топливо, состояние и остаток топливных тиков сохраняются.

Первый пассажир водит, второй в вооружённой машине — наводчик. В одиночку остановитесь и нажмите C: двигатель выключится, движение и посадка других игроков заблокируются до возврата на пост водителя. Наводчик смотрит в сторону цели; башня догоняет взгляд с ограниченной скоростью. Курс корпуса не задаётся камерой. **Танку опоры не нужны.** Самоходку сначала разворачивает водитель, затем можно перейти на пост наводчика.

Служебное действие: источник стоит на суше с работающим двигателем; цель — без пассажиров, остановлена, двигатель выключен, опоры убраны, до 12 блоков и без препятствий. Выстрелы — аркадный прямой луч, только по `HostileEntity`; без урона игрокам, питомцам, машинам и блокам. Реальная баллистика не моделируется.

**Полные условия, рецепты, боевые ограничения и результаты проверок:** [EXPANSION-ALPHA1](docs/EXPANSION-ALPHA1.md).

## Получение и установка

Есть **13 survival-рецептов**: восемь машин, рама, канистра, ремкомплект, снаряды и перезаправка канистры. Книга рецептов открывается после получения железного слитка. Машины крафтятся из новой рамы, не из упакованных машин с грузом.

Creative-вкладка содержит 12 предметов. Для теста:

```mcfunction
/give @s militaryvehicles:warden_tank
/give @s militaryvehicles:fuel_tanker
/give @s militaryvehicles:field_workshop
/give @s militaryvehicles:recovery_vehicle
/give @s militaryvehicles:bastion_howitzer
/give @s militaryvehicles:fuel_can
/give @s militaryvehicles:vehicle_shell 16
/give @s militaryvehicles:repair_kit 16
```

В **Artifacts успешной сборки из PR #6** взять `military-vehicles-0.3.0-alpha.1.jar`, не `-sources.jar` и не dev-JAR. После локальной сборки он находится в `military-vehicles/build/libs/`. Установить мод и совместимый Fabric API на сервер и все клиенты одной версии. Удалить старую версию мода из тестового профиля; не держать две одновременно.

**Использовать отдельный профиль и копию мира.** В active-миры ничего автоматически не устанавливается. Обратное понижение версии с новыми registry ID не поддерживается. Формат v1 прежний, но миграция реального мира ещё не проверена.

## Сборка и проверка

Из корня `mine`, JDK 21:

```bash
bash military-vehicles/tests/run-core.sh
bash ./gradlew -p military-vehicles --no-daemon --console=plain --no-build-cache --rerun-tasks clean build
python3 military-vehicles/tools/verify_build.py
```

Windows: `gradlew.bat` и установленный Python. Wrapper вызывается с `-p military-vehicles`, не собирая другие модули. Gate требует **93 конкретных JUnit-метода без ошибок/пропусков**, четыре standalone-набора и remapped JAR с 8 профилями, 12 предметами, 13 рецептами, 13 текстурами, 5 звуками и RU/EN.

Модели/текстуры генерируются Java/AWT; звук — build-only JAVE/FFmpeg (возможен `-PtruckFfmpeg=/path/to/ffmpeg`). Кодировщик не входит в мод. Опционально, после генерации ресурсов: `python3 military-vehicles/tools/render_fleet.py` с установленными numpy/Pillow — 18 PNG в `build/previews/`. Это **не скриншоты Minecraft**.

## Что остаётся открытым

- Minecraft-клиент, dedicated server, реальные пассажиры/камера, два клиента, миграция мира, прослушивание, FPS/MSPT и совместимость с шейдерами не проверены.
- Коллизия консервативная квадратная, подвеска и двери/рампы статические; полноценной IK и ориентированной коллизии нет. Танк/самоходка требуют особенно широкой площадки.
- Нет авиации, амфибий, AI, непрерывной буксировки, станций или синхронизируемого конфига. Настройки пока заданы профилями в коде.
- Общие бюджеты: 12 машин в радиусе 48 блоков; 8 двигателей в радиусе 32. Это ограничения, не доказательство производительности. Служебные машины используют звук грузовика, не восемь якобы уникальных петель.
- Ванильные проверки прав не означают интеграцию со всеми модами регионов; владения/замков нет. Не вкладываются предметы с `canBeNested=false`; сохранённая машина расходуется даже в creative.

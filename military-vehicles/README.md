# Military Vehicles — 0.1.0-alpha.1

Самостоятельный мод в репозитории `ProkStudio/mine`. **Minecraft 1.21.11 · Fabric Loader 0.19.5+ · Fabric API · Java 21.** Не требует Harvester или Military Arsenal, не меняет их пространства имён и сохранения. Это первый прототип грузовика, не готовый большой парк техники.

**Minecraft-клиент и выделенный сервер ещё не запускались.** Результаты реально выполненных проверок записываются в [WORKLOG](docs/WORKLOG.md). Успешная компиляция не заменяет игровую приёмку. Используйте отдельный тестовый профиль и копию мира.

## Первый транспорт: грузовик 6×6

Реализованы в коде:
- Отдельная неживая сущность `militaryvehicles:truck_6x6`, предмет размещения и собственная creative-вкладка.
- Два места; только первый пассажир управляет. Камера не задаёт курс машины.
- Серверные разгон, торможение, замедленный реверс и поворот без разворота на месте. Ступени до 0,6 блока; это игровая модель, не инженерная симуляция.
- Включаемый двигатель, бак 2400 единиц, канистра 600 единиц с сохранением остатка; ремкомплект восстанавливает 50 из 200 единиц состояния.
- Двигатель расходует 1 единицу каждые 10 тиков, в том числе на холостом ходу. Дробный накопитель расхода сохраняется при подборе и перезагрузке.
- Грузовой отсек на 27 слотов. Для защиты от вложенного хранения не принимаются предметы с `canBeNested=false` (включая этот грузовик и шалкеры); ограничения действуют и при shift-click.
- Подбор в один предмет с грузом, компонентами предметов, топливом, состоянием и именем. Предмет с сохранённым грузом расходуется при постановке **даже в creative**.
- При повреждении до нуля техника превращается в один предмет с прежним грузом и нулевым состоянием. Перед движением требуется ремонт, бесплатного восстановления нет.
- Исходная геометрия: рама, три моста и шесть колёс, кабина, кресла, приборы, руль, зеркала с креплениями, кузов, бак, выхлоп и запаска. Вращение колёс зависит от реального перемещения, передние колёса и руль поворачиваются.
- Собственные генерируемые текстуры и 3D-модели всех трёх предметов; RU/EN.

## Управление

Стандартные клавиши; смена бинда двигателя доступна в настройках. Сообщение при посадке показывает актуальный бинд двигателя и выхода.

| Действие | Управление |
|---|---|
| Поставить | ПКМ предметом грузовика по блоку |
| Сесть | ПКМ по грузовику |
| Двигатель | **G** — включить / выключить |
| Ехать / тормозить до реверса | **W / S** |
| Поворот | **A / D** |
| Тормоз | **Space** |
| Выйти | **Shift** |
| Груз | Сундук в руке + ПКМ; сундук не расходуется |
| Заправка | Канистра + ПКМ, **без Shift** |
| Ремонт | Ремкомплект + ПКМ |
| Забрать с грузом | Shift + ПКМ по остановленной пустой от пассажиров машине; нужен свободный слот |

Новый грузовик появляется **без топлива**, двигатель выключен. При отсутствии водителя, потере свежего ввода, смене водителя, открытом грузовом меню водителя или загрузке сохранения двигатель останавливается. Отпускание клавиш и потеря фокуса окна тормозят машину. Двигатель не работает при контакте с водой; амфибийность не реализована.

## Получение и установка

На текущем этапе — только creative и команды; крафт не добавлен.

```mcfunction
/give @s militaryvehicles:truck_6x6
/give @s militaryvehicles:fuel_can
/give @s militaryvehicles:repair_kit 16
```

Установочный JAR: `military-vehicles-0.1.0-alpha.1.jar`, **не** `-sources.jar` и не dev-JAR. Нужен совместимый Fabric API. На сервере и клиентах используйте одинаковую версию. Не кладите несколько версий мода в один профиль.

## Сборка независимо от остальных модулей

Из корня `mine`, JDK 21:

```bash
bash military-vehicles/tests/run-core.sh
bash ./gradlew -p military-vehicles --no-daemon --console=plain --no-build-cache --rerun-tasks clean build
python3 military-vehicles/tools/verify_build.py
```

Windows: вместо `bash ./gradlew` используйте `gradlew.bat`; `python` вместо `python3`, если так установлен Python. Wrapper и его фиксированная версия Gradle берутся из корня; корневой проект Harvester не конфигурируется из-за `-p military-vehicles`.

JAR находится в `military-vehicles/build/libs/`. Генерация ресурсов воспроизводится Java/AWT во время сборки, не требует сторонних картинок, Python или запуска игры. Python нужен только отдельному строгому verifier. Диагностическая геометрия — `build/generated/truck-geometry.json`, не включается в мод.

## Безопасность состояния и сети

Клиент отправляет только ID текущей сущности и шесть бит клавиш. Сервер проверяет первое место, текущую машину, spectator/меню, разрешённые биты, принимает не более одного обновления за тик и прекращает устаревшие команды через 10 тиков. Удержание G не переключает двигатель каждый тик. Пассажир не может рулить чужой машиной пакетом.

Формат `VehicleState` v1 использует строковый тип `truck_6x6` и строгие диапазоны. Ошибка чтения предмета отменяет постановку без его расходования. Неподдерживаемое составное состояние сущности сохраняется в исходном виде: машина становится неактивной и не открывает груз, вместо молчаливого обнуления содержимого. UUID, игроки, ввод, положение и активный двигатель в предмет не копируются. Ошибка упаковки не удаляет исходную машину.

Рядом допускается не более 12 загруженных грузовиков в радиусе 48 блоков. Размещение проверяет свободное место, границу мира, доступность чанков и ванильные права изменения мира. Это не поддержка всех сторонних модов регионов. Владения/замков нет: обслуживать и забирать незанятую технику может другой игрок.

## Честные ограничения альфы

- Коллизия пока консервативная квадратная **5,2×5,2 блока**, выше визуальной ширины. Для постановки оставьте примерно **6×6×4** свободных блока. Узкие ворота пока не поддерживаются. Это сознательный запас против прохождения носа/кормы через стены при повороте; ориентированная коллизия — отдельный этап.
- Подвеска пока статическая; двери, борта, свет и выхлоп — геометрия без интерактивной анимации. Звук и частицы двигателя ещё не добавлены.
- Посадка использует базовую ванильную позу, без полного IK и анимации рук на руле. Контакт с креслом/крышей, броня, slim-скин, камера и безопасный выход требуют игровой проверки.
- Нет танков, багги, артиллерии, вооружения, боеприпасов, AI, буксировки, полёта, станций и крафта. Их регистрация не подменена заглушками.
- Нет синхронизируемого настраиваемого конфига: текущие игровые параметры общие и фиксированы в `TruckSpec`.
- Компиляция клиентской части не означает проверку запуска клиента, сетевой игры, столкновений с другими сущностями, производительности или совместимости с шейдерами.

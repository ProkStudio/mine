# Игровая приёмка 0.1.0-alpha.1

Все пункты ниже **ещё не выполнены**. Сборка и автономные тесты не заменяют их. Проверять в отдельном тестовом профиле/мире, не на единственном сохранении пользователя; не принимать EULA и не менять действующий профиль автоматически.

- [ ] Клиент Fabric 1.21.11 и выделенный сервер запускаются; на сервере не загружаются клиентские классы.
- [ ] Creative: все 3 предмета видимы в GUI и руке; мир/предметы имеют текстуры. Resource reload не оставляет старые модели.
- [ ] Новая техника: пустой бак, выключенный двигатель; четыре канистры заполняют бак, остаток частичной канистры не теряется.
- [ ] G включается одним нажатием, удержание не дёргает двигатель; переназначенный бинд работает. W/S, A/D, Space, reverse и торможение у стены не создают телепортов.
- [ ] Первое место рулит, второе нет. Disconnect/смерть/смена мест/переход между машинами/пропажа ввода не оставляют старую тягу.
- [ ] Меню груза и потеря фокуса окна убирают тягу; у выключенной незанятой техники нет самостоятельного движения кроме падения.
- [ ] Два игрока независимо наблюдают движение/руление/колёса; два грузовика не делят анимационное состояние.
- [ ] Сохранить/выгрузить чанк/перезайти: точное топливо, накопитель расхода, состояние, имя, все 27 слотов и компоненты предметов.
- [ ] Подбор с полным грузом и повторная установка в survival/creative не дублируют груз. Полный инвентарь не удаляет машину.
- [ ] Нельзя подобрать занятую или движущуюся машину. Уже открытый грузовой экран закрывается после упаковки.
- [ ] Shift-click, обычное перетаскивание, цифровые клавиши и drag не вставляют запрещённые вложенные контейнеры.
- [ ] Ошибка/будущая версия сохранения не создаёт пустой исправный грузовик и не расходует предмет.
- [ ] Урон до нуля даёт один предмет с прежним грузом и нулевым состоянием; повторное размещение не чинит бесплатно.
- [ ] Стены, ступени/плиты, граница мира, незагруженные чанки, другие машины/игроки и контакт с водой.
- [ ] Обычный/slim-скин и броня: кресла, руки/ноги, крыша, выход слева/справа, камера от первого/третьего лица.
- [ ] Замер кадра/MSPT в описанной сцене; никаких заявлений о производительности до замера.

Записывать версию/коммит, окружение, воспроизведение и фактический результат. Логи/миры с персональными данными не публиковать целиком.

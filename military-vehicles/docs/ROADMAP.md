# План полноценного военного пака

Работа — `military-vehicles/`, `feature/military-vehicles`, draft PR #6. Пользователь просил развивать полноценный пак, а не бесконечно полировать один грузовик. Fabric/Minecraft 1.21.11/Java 21; вымышленная техника, сначала наземные машины. Игровые параметры — рабочие решения разработки, не отдельно утверждённая пользователем реалистичная модель боя.

## Дальнейшая работа

1. Выполнить [QA](QA.md) на отдельном профиле/копии мира для всех восьми машин. Сохранить реальные результаты и воспроизведение, не заменять их unit-тестами или рендерами.
2. Проверить экипаж/камеру и сетевые переходы solo/driver/gunner, меню, disconnect, опоры и сохранения.
3. Протестировать экономику крафта, заправки, ремонта, выстрелов и лебёдки; добавить проверяемую конфигурацию без дублирования систем.
4. Улучшать геометрию и анимации по игровым наблюдениям: посадка/руки, подвеска, двери/рампа, коллизия, звук/свет.
5. Измерить производительность на одинаковых сценах; закрыть ошибки перед stable. Авиация, вода, AI и постоянная буксировка — отдельные будущие объёмы, не фиктивные регистрации текущей версии.
